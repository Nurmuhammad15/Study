=== TEACHER DASHBOARD — GitHub Pages ===

FAYLLAR:
  index.html  — Sayt (GitHub Pages da ochiladi)
  keys.json   — Ustoz kalitlari (bot yozadi)
  bot.py      — Telegram bot (kompyuterda ishlaydi)

GITHUB PAGES GA JOYLASH:
1. github.com ga kiring
2. "New repository" → nom bering → Public → Create
3. "uploading an existing file" bosingва index.html + keys.json ni yuklang
4. Settings → Pages → Branch: main → Save
5. Sayt manzili: https://YOUR_USERNAME.github.io/REPO_NAME

BOT ISHGA TUSHIRISH:
  pip install pytelegrambotapi requests
  python bot.py

KALIT OLISH:
  Botga /getkey yuboring → kalit oling → keys.json ni GitHub ga push qiling
